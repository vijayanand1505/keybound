# KEYBOUND game-library art direction — v0.13

Three original covers were created with the **built-in imagegen tool**, using the imagegen skill in default built-in mode. No CLI fallback, stock libraries, reference photographs or third-party game art were used. The selected PNGs are saved inside this project and served through Next.js Image optimization; all titles and controls remain HTML.

| Asset | Saved source | Uses |
| --- | --- | --- |
| Storm Coast | [storm-coast.png](../public/images/games/storm-coast.png) | Selected story feature and coast game card |
| White Ascent | [white-ascent.png](../public/images/games/white-ascent.png) | Selected story feature and mountain game card |
| Signal Siege | [signal-siege.png](../public/images/games/signal-siege.png) | Featured arcade panel, orbit card, launch screen, Open Graph/Twitter preview |

The interface uses neutral ink and warm cream surfaces with the existing selectable accents. DM Sans remains the interface font; IBM Plex Mono remains the typing font. Cover hover movement is disabled for both system and in-game reduced motion. Gameplay art and rules, local records, keyboard audio, fullscreen behavior and the name-only developer credit are preserved.

## Final prompt set

### coast

Use case: stylized-concept. Asset type: landscape key art for KEYBOUND's Storm Coast typing adventure, used on website game cards and an illustrated feature panel. Primary request: create one original premium cinematic game environment cover, wide 3:2 landscape composition. Scene: a solitary stone lighthouse on a rugged coastal cliff, tall storm clouds, layered Atlantic waves and one tiny ship in the distance. Style: sophisticated painterly 3D game concept art with detailed materials, atmospheric depth, subtle film grain and beautifully restrained light. Lighting: blue hour slate-blue sea and dark pine cliffs, a strong warm champagne-gold lighthouse beam through mist. Composition: lighthouse and cliff in the right half, open darker ocean and sky on the left for separately rendered HTML title text; a readable strong silhouette at thumbnail size. Color continuity: dark ink, blue teal, amber gold highlights. No people close-up, no letters, no text, no typography, no logo, no watermark, no border, no UI. This is background artwork only, not a website mockup.

### ascent

Use case: stylized-concept. Asset type: landscape key art for KEYBOUND's White Ascent typing adventure, used on website game cards and an illustrated feature panel. Primary request: create one original premium cinematic game environment cover, wide 3:2 landscape composition. Scene: a vast snowy mountain ridge with a tiny golden tent and weather-station light at the foot of a towering summit, distant peaks receding through thin cloud. Style: sophisticated painterly 3D game concept art, detailed snow and rock, atmospheric depth, subtle film grain, restrained and premium. Lighting: icy silver-blue snow, deep slate shadows, a narrow warm sunrise glow along the summit and a tiny amber tent light. Composition: tallest summit in the right half, calm shadowed terrain and clear negative space at lower left for separately rendered HTML text. Strong silhouette and readable depth at thumbnail size. Color continuity: dark ink, blue teal and restrained champagne gold. No text, typography, logo, watermark, border, UI or close-up people. Background artwork only, not a website mockup.

### orbit

Use case: stylized-concept. Asset type: landscape key art for KEYBOUND's Signal Siege / Low Orbit space typing shooter, used on website feature panels and game cards. Primary request: create one original premium cinematic space-game cover, wide 3:2 landscape composition. Scene: a sleek small triangular relay fighter with pale cyan thrusters seen from a rear three-quarter angle, crossing above the immense curved limb of an ocean planet; a distant orbital station and a few tiny hostile drone silhouettes ahead. Style: sophisticated painterly 3D game concept art, convincing metal materials, cinematic atmospheric scale, subtle film grain, crisp enough for a premium indie game cover. Composition: fighter prominent in the right half pointing up and right, planet rim sweeping diagonally across the lower third, dark open star field on the left for separately rendered HTML text. Lighting: deep midnight ink, cool teal atmosphere, soft champagne-gold rim light on the fighter and a restrained warm distant star. No text, letters, logos, numbers, typography, UI, borders, explosions covering the ship or watermark. Background artwork only, not a website mockup.
